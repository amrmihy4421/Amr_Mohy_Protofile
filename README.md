# Amr Mohy — Full Stack Developer Portfolio

A static, responsive portfolio built with HTML, CSS, and vanilla JavaScript. It includes English and Arabic content, RTL layout, dark and light themes, project details, and the animated About section.

## Projects

- **KiRA Women's Wear** — full stack e-commerce project.
- **DyspnEA** — AI-powered respiratory health assistant.

Project images and other static assets are stored in `assets/`.

## Run locally

Serve this folder with any static file server, then open its local URL. The project has no package installation or build step.

## Publish with GitHub Pages

1. Create a repository named `amr-mohy-portfolio` under `amrmihy4421` and upload the contents of this folder to the repository root. Keep the `assets` folder and its contents.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.

GitHub Pages will publish the static site from the repository root. No build command, output directory, secrets, or Vercel configuration is required. The expected site address is `https://amrmihy4421.github.io/amr-mohy-portfolio/` after GitHub finishes publishing.
